# 墨西哥每日一字 · 單字卡瀏覽器

> 🇲🇽 互動式墨西哥西班牙語每日單字卡瀏覽器
> 左右切換瀏覽每天學過的單字卡、點喇叭聽發音、標記「我知道了 / 我要學習」追蹤進度。

## 線上使用

直接開啟 GitHub Pages 即可使用：
https://nelsonliu92.github.io/mexican-spanish-flashcards/

## 功能特色

- 📱 手機友善 RWD 設計
- 🔊 點擊喇叭圖示播放西語發音（TTS）
- ⬅️ ➡️ 左右切換 / 鍵盤方向鍵瀏覽
- ✅ 標記「我知道了」追蹤學習進度
- 📌 收藏按鈕
- 📊 進度條顯示整體掌握度
- 🖼️ 每張卡片搭配 AI 生成情境插圖

## 檔案結構

```
├── index.html          ← 單字卡瀏覽器主程式
├── manifest.js         ← 每日單字卡資料（結構化 JSON）
└── 每日一字/           ← 每日單字卡情境插圖（不含文字，瀏覽器即時排版）
    ├── 2026-09-01-photo.jpg
    ├── 2026-09-02-photo.jpg
    └── ...
```

## 資料格式

```javascript
{
  date: "YYYY-MM-DD",
  image: "每日一字/YYYY-MM-DD-photo.jpg",
  word_es: "西語單字例句",
  pos: "詞性",
  word_zh: "中文翻譯",
  desc_zh: "中文說明",
  example_es: "西語例句",
  example_zh: "例句中文翻譯"
}
```
